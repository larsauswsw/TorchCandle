# Candle

Eine iOS-App, die die rückseitige LED (Blitz) statt konstant an/aus in einem
Kerzenflacker-Muster betreibt.

## Bauen

Voraussetzung: [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)

```bash
xcodegen generate
open Candle.xcodeproj
```

Wähle dein iPhone als Run-Ziel und starte die App — die Taschenlampe braucht
echte Hardware und funktioniert nicht im Simulator.
